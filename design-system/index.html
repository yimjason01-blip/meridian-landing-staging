Reference page

This page is the primary visual-language source. Website and live pages are implementation evidence; the Reference page defines the initial system lanes.

figma-referenceHero treatment
  • Full-bleed aspirational photography.
  • Warm rust/orange into navy/purple gradients.
  • Axis-aligned rectangular mosaic blocks only.
  • White lowercase wordmark and square ghost actions.
figma-referenceTrajectory language
  • Cream grid field, not dark cinematic render.
  • PolySans narrative headline over chart.
  • Space Mono axis and section nav labels.
  • Gradient curve, square markers, dashed counterfactual.
figma-referenceIllustration systems
  • Set A: isometric warm-brown object illustrations with dark stroke.
  • Set B: flat outlined icons with registration/crop-mark corners.
  • Icons explain status moments, not decorative chrome.
figma-referenceTexture moments
  • Mobile status/interstitial screens.
  • Single centered illustration or icon.
  • One bottom-anchored CTA.
  • Warm texture or approved Reference gradient as full-bleed surface.
Use

Reference-page exports, exact node colors where available, square geometry, warm/cool gradients, cream grid fields, isometric and outlined icon lanes.

Do not use

The old curve thumbnail as canonical, dark gold `curve.jpg`, rounded/frosted CTA families, generic health-tech HUDs, or unlabeled screenshot artifacts.

Patterns

Page sections

live-hero
Landing hero reference
z 1Background planePhoto base and broad background color/image crop. Uses `--slide-image-shift` during carousel transitions.
z 2Mid-blocks planeFigma color blocks and grid masses. Uses `--slide-float-shift` plus scroll parallax.
z 3Subject planeForeground person or scene cutout. Travels with the image shift, not the floating-block shift.
z 4Anchor block planeStatic Figma anchor shapes. Transform stays `none` so the frame does not drift.
z 8 to 9DOM chromeLogo, Log In, headline, CTA, counters, and dots are real DOM above the artwork.

Carousel mechanics

Inactive slides start at `--slide-image-shift: 112vw` and `--slide-float-shift: 230vw`. Active slides set both to `0px`. Exiting slides move to `-58vw` image shift and `-170vw` float shift.

Scroll parallax

On scroll, only the mid-blocks plane receives `--hero-floating-block-shift`. Formula: progress equals `scrollY / heroHeight`, clamped 0 to 1. Max shift is `min(10vw, 150px)`, applied left as a negative translate.

Motion guard

`prefers-reduced-motion: reduce` disables the floating block transform and shortens animation durations. Updates are throttled through `requestAnimationFrame`.

Source files

Implementation lives in `figma-hero-shot.html`; layer inventory lives in `figma-layer-manifest.md`; image planes live under `assets/figma-hero-layers/`.

.hero-bg-plane       { z-index: 1; transform: translate3d(var(--slide-image-shift), 0, 0); }
.hero-mid-blocks-plane { z-index: 2; transform: translate3d(calc(var(--slide-float-shift) + var(--hero-floating-block-shift, 0px)), 0, 0); }
.hero-subject-plane  { z-index: 3; transform: translate3d(var(--slide-image-shift), 0, 0); }
.hero-anchor-block-plane { z-index: 4; transform: none; }

Verification

Before shipping a page, check asset paths, button radius, token usage, mobile layout, focus states, and image loading.
